# نظام التشغيل بروفيشنال - Online

نسخة خادم من النظام بدل localStorage. البيانات تحفظ في SQLite على السيرفر، وتسجيل الدخول يتم بجلسة خادم وصلاحيات حسب الدور.

## التشغيل
1. ثبّت Node.js 20+.
2. نفّذ: `npm install`
3. انسخ `.env.example` إلى `.env` وعدّل `SESSION_SECRET` والأكواد.
4. نفّذ: `npm start`
5. افتح: `http://localhost:3000`

## ملاحظات مهمة للنشر
- استخدم HTTPS.
- استخدم `SESSION_SECRET` عشوائي طويل.
- احتفظ بمجلد `data/` على تخزين دائم؛ ملف قاعدة البيانات `professional.db` موجود بداخله.
- اعمل نسخًا احتياطية منتظمة لملف قاعدة البيانات.
- الأكواد الموجودة في `.env.example` للاختبار فقط، ويجب تغييرها قبل الاستخدام الحقيقي.
- النظام يطلب الكود عند كل تحميل للواجهة، ولا يعتمد على localStorage للأوردرات.

## الصلاحيات
- المدير: كل الأقسام + حذف الأوردر.
- خدمة العملاء: العملاء والأوردرات + إنشاء وتعديل الأوردر وتغيير الحالة وتعيين الفني.
- الفني: أوردراته فقط + تغيير حالة الأوردر.
